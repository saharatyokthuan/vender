# 🥤 Vending Stock Manager

ระบบจัดการสต๊อกตู้จำหน่ายสินค้าอัตโนมัติ — ทำงานแบบ **Offline-first** บนเบราว์เซอร์
ไม่ต้องติดตั้ง ไม่ต้องใช้เซิร์ฟเวอร์ ไม่มี dependency

---

## ✨ ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 📦[](จัดการสินค้า) | เพิ่ม / แก้ไข / ลบ พร้อมปุ่ม `+` `−` ปรับสต๊อกเร็ว |
| 🗂️ หมวดหมู่ | แยกสินค้าเป็นหมวด พร้อมแถบแสดงระดับสต๊อก |
| ⚠️ แจ้งเตือนอัตโนมัติ | สต๊อกหมด · ต่ำกว่าเกณฑ์ · ใกล้หมดอายุ · หมดอายุแล้ว |
| 📊 สรุปยอด | จำนวน SKU, จำนวนชิ้น, มูลค่าสต๊อกรวม, แยกตามหมวด |
| 💾 สำรอง / กู้คืน | Export & Import ไฟล์ JSON |
| 📱 Responsive | ออกแบบสำหรับมือถือ (max-width 520px) |

---

## 🚀 การติดตั้ง

```bash
# 1) เปลี่ยนชื่อไฟล์
mv index.txt index.html

# 2) เปิดใช้งาน — วิธีที่ง่ายที่สุด
open index.html

# หรือรันผ่าน local server (แนะนำ)
python -m http.server 8000
# → http://localhost:8000
```
